# 그래보드 · GraeBoard

**함께 그려가는 일의 흐름.**

그래보드는 팀의 주간 업무와 연간 일정을 셀 형태로 관리하는 웹앱입니다. 팀원별 업무를 모아 보고, 필요한 기간과 속성만 표시하며, 셀에서 바로 내용을 편집합니다. React · TypeScript · Node.js · SQLite로 구성되어 자체 서버에서 운영할 수 있습니다.

## 주요 기능

- **연간 업무 표**: 셀 직접 편집, 범위 선택, 서식을 포함한 복사·붙여넣기, 실행취소·재실행, 행 순서 이동
- **기본 서식**: 공통 툴바와 미리보기, 팀 기본 셀 높이, 글자·배경색, 한글 글꼴 5종, 6~36pt, 정렬, 오버플로우·줄바꿈·자르기
- **콤팩트 업무 표**: 상단 메뉴, 월·주차 드래그 기간 선택, 전체 속성 찾기·결과 셀 이동·속성 필터, 열 메뉴의 묶음·정렬·고정, 행·열 숨김, 개인별 저장된 필터
- **팀 스페이스**: 복수 팀 배속, 동적 속성, 팀 양식 복사, 팀별 기본 서식과 파스텔 테마 5종
- **업무 기록**: 상태별 통계, 읽기 전용 주간 보고본, 변경 이력과 복원, 휴지통, 다음 연도 표시
- **이관·반출**: XLSX 가져오기, XLSX·CSV·JSON 내보내기, SQLite 백업·복구
- **발표 모드**: 현재 보기를 표만 표시하는 화면으로 전환

새 팀의 기본 속성은 **작업·팀원·상태**입니다. 상태는 예정·검토 중·진행 중·완료·보류를 제공하며, 기본 서식은 **9pt**, 세로 정렬은 **중간**, 셀 높이는 **편안하게**, 왼쪽 열은 **고정 안 함**입니다.

## 빠른 시작

Node.js **22.13 이상**과 npm이 필요합니다.

```sh
git clone https://github.com/hwantage/GraeBoard.git
cd GraeBoard
npm ci
npm run build
npm start
```

<http://127.0.0.1:4310>에 접속하여 첫 관리자 계정과 팀을 만듭니다. 기본 계정이나 비밀번호는 없습니다. 최초 설정의 예시 업무 생성은 선택 사항입니다. 빈 공간으로 시작하려면 예시 업무 옵션을 해제하세요.

실행 시 데이터베이스는 `data/weekly-plan.sqlite`에 생성됩니다. 저장소에는 실제 계정·업무 데이터·데이터베이스·백업·환경 비밀값을 포함하지 않습니다.

개발 중에는 다음 명령을 사용합니다. 화면은 <http://127.0.0.1:5173>, API는 `4310` 포트입니다.

```sh
npm run dev
```

## 검증

```sh
npm test
npm run build
npx playwright install chromium firefox webkit
npm run test:e2e
```

자동 검사는 임시 데이터베이스를 사용합니다. 브라우저 검사는 `4311` 포트를 사용하므로 해당 포트를 비워 두세요. 자세한 절차와 결과 범위는 [개발 안내](docs/DEVELOPMENT.md#검증)를 참고하세요.

## 구성과 운영 범위

브라우저는 React 가상 그리드를 사용하고, Express API가 권한·입력·동시 수정 버전을 검사하여 SQLite에 저장합니다. 운영은 **단일 서버와 로컬 디스크**를 기준으로 합니다. HTTPS와 접근 범위, 백업 보관은 운영 환경에 맞게 구성해야 합니다.

Pretendard·Noto Sans KR·Noto Serif KR·Nanum Gothic Coding은 앱에서 직접 제공합니다. 맑은 고딕은 PC에 설치된 글꼴을 사용하며 없으면 Pretendard로 표시합니다. Google API나 외부 폰트 서버는 실행에 필요하지 않습니다.

계산식·함수, 셀 병합, 셀 내부 부분 서식, 외부 SSO, 첨부파일, 오프라인 편집은 제공하지 않습니다. 텍스트의 여섯 자리 이슈 번호는 현재 사내 Redmine 주소로 연결되며, 연결 규칙은 [개발 안내](docs/DEVELOPMENT.md#확장과-변경)에서 설명합니다.

의존성 고지 원문은 [THIRD_PARTY_NOTICES.txt](docs/THIRD_PARTY_NOTICES.txt)에 있습니다. 현재 저장소에는 애플리케이션 소스의 별도 오픈소스 라이선스를 지정하지 않았습니다.

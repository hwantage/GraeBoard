# 그래보드 사용 안내

[처음으로](../README.md) · [운영 안내](OPERATIONS.md) · [데이터 형식](DATA_FORMAT.md)

## 1. 업무와 일정 작성

업무 한 건이 하나의 행이며, 오른쪽 주차 열에 주간 일정을 기록합니다. 날짜 헤더는 월/일로 표시합니다. **업무 추가**를 누르면 현재 보기의 맨 아래에서 제목을 입력합니다. 묶음 보기에서는 새 업무를 미지정 묶음에 추가하고, 열 정렬은 기본 순서로 전환합니다. 새 업무를 가리는 필터는 해제됩니다.

일반 텍스트 셀은 더블클릭하거나 선택 후 Enter/F2 또는 문자를 입력하면 편집합니다. Option·Member 속성은 표시된 칩이나 글자를 한 번 눌러 선택 목록을 엽니다. 빈 속성 셀은 더블클릭합니다. 셀의 빈 여백은 셀 선택에 사용합니다.

| 입력 | 동작 |
| --- | --- |
| Enter | 저장 후 다음 행으로 이동 |
| Tab / Shift+Tab | 저장 후 다음 / 이전 셀로 이동 |
| Shift+Enter | 텍스트 줄바꿈 |
| Esc | 현재 편집 취소 |
| 다른 셀 클릭 | 입력 저장 후 선택 이동 |
| Shift+클릭 / 마우스 드래그 / Shift+방향키 | 여러 셀 선택 |

한글 조합 중 Enter는 저장 단축키로 처리하지 않습니다. 편집 중에도 행 높이는 유지합니다.

열 머리글을 클릭하면 해당 열 전체가, 왼쪽 행 번호를 클릭하면 해당 행 전체가 선택됩니다. 머리글·행 번호를 드래그하거나 Shift+클릭하면 연속된 여러 열·행을 선택합니다. 선택한 범위에 서식 도구의 글자 크기·배경색 등을 적용할 수 있습니다. 화면 밖의 행도 포함하고, 필터·숨김으로 제외된 행과 숨긴 열은 포함하지 않습니다. 왼쪽 위 **#**는 현재 보기의 모든 셀을 선택합니다.

번호 칸은 **왼쪽 이동 손잡이 · 숨김 구간 화살표 · 행 번호 선택**로 나뉩니다. 이동 손잡이를 드래그하면 옮길 행이 흐리게 표시되고, 업무명과 삽입 위치선이 나타납니다. 행 번호를 드래그하거나 Shift+클릭하여 여러 행을 선택한 뒤, 선택한 행 중 하나의 손잡이를 끌면 기존 순서 그대로 함께 이동합니다. 숨기거나 필터로 제외한 행은 이동 대상에 포함하지 않습니다. Esc로 취소하면 기존 선택을 유지합니다. **묶음 보기에서는 같은 묶음 안에서만** 이동하며, 선택한 모든 행에 편집 권한이 있어야 합니다. 손잡이에 초점을 두고 Alt+위/아래 방향키로도 선택한 행들을 함께 옮길 수 있습니다. 컬럼 정렬 중에는 머리글 우클릭 메뉴에서 먼저 **정렬 해제**를 선택합니다.

행 번호를 우클릭하고 **업무 상세**를 선택하면 업무 상세가 열립니다. 속성값을 누르면 해당 셀 편집으로 이동하고 숨긴 열도 펼칩니다. 숨기기·복제·위/아래 이동·다음 연도 표시·휴지통 동작을 제공합니다. 다음 연도에도 표시한 업무는 같은 ID와 일정을 공유합니다.

⌘(Mac)/Ctrl(Windows)을 누른 채 셀·머리글·행 번호를 클릭하거나 드래그하면 떨어진 영역을 추가 선택합니다. 일반 클릭은 새 선택으로 바꾸며 Esc는 전체 선택을 해제합니다.

## 2. 서식과 복사

서식 도구에서 글자색·배경색, 글꼴, 6~36pt 크기, 가로·세로 정렬, 굵게·기울임·밑줄·취소선을 지정합니다. **⌘/Ctrl+B**는 선택한 모든 영역의 굵게를 켜거나 끕니다. 셀 입력 중에도 입력 내용을 유지하며 해당 셀에 적용합니다. 여러 셀에 서로 다른 서식이 섞여 있어도 메뉴의 현재 값을 다시 선택하면 전체 선택 범위에 적용됩니다.

| 설정 | 기본값 / 동작 |
| --- | --- |
| 새 팀 글자 크기 | 9pt |
| 새 보기 셀 높이 | 편안하게 |
| 왼쪽 열 고정 | 고정 안 함 |
| 셀 좌우 여백 | 일반·날짜·주간 일정 셀 모두 4px |
| 글꼴 | Noto Sans KR, Pretendard, 맑은 고딕, Noto Serif KR, Nanum Gothic Coding |
| 셀 높이 | 넉넉하게·편안하게·촘촘하게. 촘촘하게는 편안하게의 약 2/3 |

맑은 고딕은 설치된 글꼴을 사용하고, 없으면 Pretendard로 표시합니다. 기존 업무에 저장된 서식은 기본값 변경으로 일괄 수정되지 않습니다.

**텍스트 표시**는 다음 세 가지를 제공합니다.

- **오버플로우**: 기본 동작입니다. 오른쪽의 연속된 빈 셀까지 표시하고 다음 값 또는 고정 영역 경계에서 자릅니다.
- **줄바꿈**: 셀 너비에 맞춰 여러 줄로 표시합니다.
- **자르기**: 자신의 셀 끝에서 말줄임표 없이 자릅니다.

줄바꿈과 위·중간·아래 정렬은 별도로 설정합니다. 여러 줄 내용이 셀 높이를 넘으면 첫 줄부터 표시합니다. 열 경계와 번호 열의 아래 경계를 끌어 너비·높이를 조절할 수 있습니다.

**테두리** 버튼에서 선 스타일·색상을 정한 뒤 **바깥쪽 테두리**, **모든 테두리**, **테두리 지우기**를 선택합니다. 떨어진 영역은 각각 적용하고, 맞닿거나 겹친 영역의 바깥쪽 테두리는 합쳐진 선택의 외곽에 적용합니다. 실행취소·재실행을 지원합니다.

복사·붙여넣기 단축키나 **선택 셀 복사** 버튼으로 내용과 셀 서식을 함께 복사합니다. 한 번에 2,000셀까지 처리하고 빈 셀의 배경색도 유지합니다. 일반 텍스트를 붙이면 대상 셀의 기존 서식을 유지합니다. 셀 내부 편집 중에는 텍스트만 붙여넣습니다. 숨기거나 필터에서 제외한 행은 범위 편집에서 제외됩니다. 내용 변경 없이 서식만 적용할 때는 한 번에 50,000셀까지 지원합니다.

복사·붙여넣기는 하나의 연속된 영역에서 사용합니다. 셀 테두리도 HTML·앱 클립보드와 XLSX 반출·이관에 포함합니다.

외부 HTML 표는 지원하는 셀 단위 서식만 가져옵니다. 셀 병합과 셀 내부 부분 서식은 지원하지 않습니다. 수식처럼 보이는 문자열은 계산하지 않고 텍스트로 저장합니다. 여섯 자리 이슈 번호는 설정된 Redmine 주소의 링크로 표시합니다.

## 3. 기간과 보기

첫 번째 줄에는 연도, 주차 이동, 이번 주, 연간 전체, 월·분기·반기 선택을 모았습니다. 팀이나 연도를 전환하면 가로 스크롤은 맨 왼쪽 업무 열에서 시작합니다. **이번 주**와 **주차 이동**을 직접 선택하면 해당 날짜로 이동합니다.

두 번째 줄의 **묶음 보기**에서 속성을 선택해 같은 값끼리 모읍니다. 묶음 순서는 속성 관리의 값 순서를 따르며 미지정 값은 마지막입니다. 컬럼 머리글을 **우클릭**하면 **열 숨기기·오름차순 정렬·내림차순 정렬·정렬 해제** 메뉴가 열립니다. 여러 열을 선택한 채 우클릭하면 선택을 유지하며, 숨기기는 선택 열에, 정렬은 우클릭한 열을 기준으로 적용합니다. 작업 열은 숨기지 않으며 날짜 열에는 정렬을 제공하지 않습니다. 행 번호 우클릭에서는 선택한 행을 숨길 수 있습니다. 머리글에 초점을 두고 Shift+F10으로도 메뉴를 열 수 있습니다.

팀원·속성 필터는 여러 값을 선택할 수 있습니다. 같은 필터 안의 값은 OR, 서로 다른 필터는 AND로 적용합니다. 팀원 필터는 팀원/지원자/둘 중 하나를 기준으로 선택합니다. 검색, 나의 업무와 함께 사용할 수 있습니다.

**보기 설정**에서 열 표시, 왼쪽 열 고정, 셀 높이, 월 접기, 주차·행 숨김을 관리합니다. 보기 설정은 사용자·팀·연도별로 저장됩니다. **저장한 보기**로 자주 쓰는 조건을 보관할 수 있습니다. 숨김 해제는 필터를 유지하며, 보기 초기화는 필터·숨김·열 크기를 기본값으로 돌립니다.

행을 숨겨도 나머지 행 번호는 유지됩니다. 이동 손잡이와 행 번호 사이의 작은 삼각형을 누르면 해당 구간만 펼칩니다. 손잡이 오른쪽의 빈 부분도 행 선택 영역이며, 실제 삼각형 버튼을 누른 경우에만 숨김을 해제합니다. 맨 위·아래 구간과 전체 행을 숨긴 경우에도 펼치기 버튼을 제공합니다. 검색·필터로 제외된 행에는 숨김 표시를 만들지 않습니다.

숨긴 속성·주차 열은 머리글 경계 위쪽에 **좌우 화살표**로 표시합니다. 화살표 전용 열이나 빈 칸을 추가하지 않으므로 보이는 열은 바로 맞닿습니다. 화살표를 누르면 해당 구간만 펼치며, 맨 앞·뒤 열과 표시 기간의 모든 주차를 숨긴 경우에도 복원할 수 있습니다. 조회 기간 밖의 주차와 접은 월은 이 표시에서 제외합니다. 별도의 숨긴 주차 목록 영역은 표시하지 않습니다.

## 4. 팀·팀원·속성 관리

**팀과 계정 관리**는 네 탭으로 구성됩니다.

| 탭 | 기능 |
| --- | --- |
| 팀 관리 | 팀 생성·이름 변경, 팀원 복수 배정, 양식 복사, 테마, 팀 삭제 |
| 팀원 관리 | 계정 추가·수정·활성화, 역할, 복수 팀 배속, 전체·팀별 목록 필터 |
| 속성 관리 | 이름·종류·표시·순서·선택값·색상·컬럼 표시 여부 |
| 기본 서식 | 새 업무와 빈 일정 셀에 적용할 팀별 글꼴·크기·색상·정렬 |

팀원 추가·수정의 **프로필 아바타**에서 이름 첫 글자(기본), 영문 1~3자 또는 한글 1~2자 직접 입력, 이미지 업로드 중 하나를 선택합니다. 배경색도 지정할 수 있습니다. 이미지는 5MB 이하의 PNG·JPEG·WebP를 사용하며 중앙을 정사각형으로 맞춥니다. 이름 첫 글자로 전환하면 업로드 이미지를 지울 수 있습니다.

팀에서 제외된 팀원도 기존 업무에는 최신 이름·아바타·배경색으로 표시됩니다. 필터와 새 담당자 선택 목록에서는 제외됩니다. 기존 배정을 다른 값으로 바꾸거나 해제한 뒤에는 다시 선택할 수 없습니다. 보고본은 생성 시 저장한 프로필 사본을 유지합니다.

새 팀은 **작업·팀원·상태** 세 속성을 만듭니다. 새 팀 생성 시 **새 팀 양식**에서 다른 팀을 선택하면 속성·선택값·표시·순서·기본 서식·테마를 복사합니다. 업무와 계정 배정은 복사하지 않습니다.

속성 관리에서 **주차 날짜**를 선택하면 날짜 묶음의 **왼쪽·오른쪽 경계선 스타일과 색상**을 따로 지정할 수 있습니다. 속성 저장 후 팀 전체에 적용되며, 조회 기간이나 숨긴 주차가 바뀌면 현재 표시되는 첫·마지막 날짜에 따라갑니다. 이 경계에서는 팀 경계선이 개별 셀 테두리보다 우선합니다.

테마는 민트·하늘·라벤더·로즈·샌드 중 선택합니다. 팀 메뉴·버튼·선택 강조에 적용하며, 업무 셀과 속성 칩의 개별 색상은 유지합니다.

팀 목록의 저장 버튼 오른쪽 **휴지통**은 확인 후 팀의 모든 연도 업무·일정·보고본·보기·이력·설정 등을 영구 삭제합니다. 이 동작은 앱에서 복구할 수 없습니다. 사용자 계정과 다른 팀의 데이터는 유지합니다. 활성 시스템 관리자의 유일한 소속 팀은 다른 팀에 먼저 배정해야 삭제할 수 있습니다.

### 속성과 상태 통계

| 종류 | 입력과 표시 |
| --- | --- |
| Option | 일반 텍스트·원형 칩·사각형 칩·포인트 칩·이모지 칩 |
| Text | 일반 텍스트 |
| Date | 날짜 |
| Number | 숫자 |
| Member | 단일·복수 팀원, 텍스트·아바타 |

속성 이름·컬럼 순서·표시 여부를 변경하고 추가 속성을 만들 수 있습니다. 선택값 이름은 최대 15자입니다. 값마다 표시 순서와 배경색을 정하며, 포인트 칩은 점 색상을 별도로 지정합니다. 이모지 칩에는 색상 설정이 없습니다.

왼쪽 목록의 **주차 날짜**는 전체 날짜 열을 나타내며 처음에는 맨 아래에 있습니다. 위·아래 버튼으로 진척률·목표일 등의 속성을 **주차 날짜 아래로** 옮기고 **속성 저장**을 누르면 표에서도 마지막 날짜 뒤에 배치됩니다. 주차 날짜 항목 자체도 이동할 수 있습니다. 같은 쪽에 놓인 속성은 목록 순서를 따르며, 조회 기간을 줄이거나 월·주차를 숨겨도 뒤쪽 속성은 표시 중인 날짜 다음에 유지됩니다. 모든 주차를 숨겨도 속성 열은 남습니다. 이 배치는 팀 공통 설정이며 새 팀 양식·새 보고본·내보내기에도 반영됩니다. 왼쪽 열 고정은 주차 날짜 앞의 표시된 업무 정보 열만 대상으로 합니다.

작업·팀원·상태는 삭제나 종류 변경이 불가능합니다. 이름과 표시 순서는 변경할 수 있습니다. 권한에 연결된 팀원과 지원자는 Member 종류 및 단일·복수 구성을 유지합니다. 지원자는 보관·복원이 가능합니다. 속성 삭제는 경고 후 보관 처리하며 기존 셀 값을 보존합니다. 저장 전 빈 초안은 바로 제거합니다.

상태는 예정·검토 중·진행 중·완료·보류를 기본 제공하고 활성 선택값이 하나 이상 필요합니다. 상단 통계는 상태 속성의 이름·값·색상·순서에 맞춰 **현재 팀·연도의 전체 업무**를 집계합니다. 필터·숨김과 무관하며, 빈 상태는 미지정, 보관된 옛 값은 기존 값으로 합산합니다.

### 역할

| 역할 | 기본 범위 |
| --- | --- |
| 시스템 관리자 | 계정·팀·배속 관리, 소속 팀 업무 관리 |
| 팀 관리자 | 소속 팀의 업무·속성·기본 서식 관리 |
| 팀원 | 자신이 담당하거나 지원하는 업무 편집 |
| 열람자 | 조회·필터·개인 보기·내보내기 |

서버에서도 소속 팀과 권한을 검사합니다. UI에서 숨기는 것만으로 편집을 제한하지 않습니다.

## 5. 저장과 이력

셀 편집을 확정하면 저장을 요청합니다. 실패한 입력은 화면에 남으며 **입력 확인**에서 다시 시도하거나 최신 버전을 확인한 후 재적용합니다. 로그인 만료 시 재인증하여 입력을 복구합니다. 저장 중이거나 실패한 입력이 있으면 로그아웃을 제한합니다.

다른 사용자의 변경은 약 7초 간격으로 조회합니다. 동시에 바뀐 셀은 버전 충돌을 안내합니다. 실행취소·재실행은 현재 팀·연도의 편집 세션에서 최근 50개 작업을 지원하고, 다른 사람이 수정한 버전은 덮어쓰지 않습니다. 삭제 업무는 관리자 휴지통에서 복구합니다.

오프라인 편집 저장소는 제공하지 않습니다. 미저장 입력이 있을 때 탭을 닫으면 복구하지 못할 수 있습니다.

## 6. 보고본과 발표

주간 보고본은 현재 보기에 포함된 업무, 당시 사용자와 속성, 표시 조건과 서식을 보관합니다. 읽기 전용이며 원본 업무를 이후에 수정해도 바뀌지 않습니다.

**발표 모드**에서는 메뉴와 툴바를 숨기고 현재 필터·묶음·숨김을 적용한 표만 표시합니다. 편집은 잠깁니다. Esc 또는 오른쪽 아래 발표 종료 버튼으로 돌아오면 원래 위치를 복원합니다. 종료 버튼은 잠시 뒤 숨겨지고 해당 위치에 마우스를 올리거나 Tab으로 초점을 주면 나타납니다.

## 7. 가져오기·내보내기

1. 원본 시트를 XLSX로 반출해 별도 보관합니다.
2. 팀·팀원과 필요한 속성·선택값을 먼저 등록합니다.
3. 가져오기에서 대상 시트·연도·담당자 연결·예외 목록을 검토합니다. 미리보기는 업무를 변경하지 않습니다.
4. 최신 시트는 업무로, 과거 날짜별 시트는 보고본으로 적용할 수 있습니다. 동일 파일·팀·시트·모드·연도 재시도는 중복 생성하지 않습니다.
5. 행 수·날짜·담당자·서식·숨김 구간을 원본과 대조합니다. 가져온 숨김 조건은 저장한 보기에서 선택합니다.

파일은 최대 25MB, 150시트, 시트당 20,000행·500열을 처리합니다. 압축 해제 크기도 검사합니다. 첫 20행에서 헤더를 찾고 날짜는 월요일 주차 키로 연결합니다. 담당자 이름이 중복되면 직접 연결해야 합니다. 같은 팀에 정의된 동적 속성은 표시명으로 연결합니다.

수식은 파일에 저장된 결과값으로 변환합니다. 결과값 없는 수식, 병합, 조건부 서식, 차트·매크로, 부분 서식 등은 검토가 필요합니다. 이관은 변경분 자동 병합 기능이 아니므로 원본을 보관하고 결과를 확인하세요.

| 내보내기 | 포함 범위 |
| --- | --- |
| XLSX | 값과 기본 셀 서식 |
| CSV | 값. 수식으로 실행될 수 있는 텍스트는 작은따옴표로 보호 |
| JSON | 업무 ID·날짜 키·서식·개인 보기·관리자 보고본 등 |

현재 표시 범위와 연도 전체를 구분하여 내보냅니다. 파일명은 `graeboard-연도.확장자`입니다. JSON 직접 재가져오기는 제공하지 않습니다. 계정·권한·이력을 포함한 전체 복구는 [SQLite 백업·복구](OPERATIONS.md#백업과-복구)를 사용하세요.

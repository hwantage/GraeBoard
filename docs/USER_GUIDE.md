## 1. 업무와 일정 작성

업무 한 건이 하나의 행이며, 오른쪽 주차 열에 주간 일정을 기록합니다. 날짜 헤더는 월/일로 표시합니다. **업무 추가**를 누르면 현재 보기의 맨 아래에서 제목을 입력합니다. 팀원·상태를 포함한 나머지 속성은 빈값으로 시작합니다. 일반 팀원도 자신이 만든 미지정 업무를 편집할 수 있습니다. 묶음 보기에서는 새 업무를 미지정 묶음에 추가하고, 열 정렬은 기본 순서로 전환합니다. 새 업무를 가리는 필터는 해제됩니다.

일반 텍스트 셀은 더블클릭하거나 선택 후 Enter/F2 또는 문자를 입력하면 편집합니다. Option·Member 속성은 칩·글자·빈 셀 모두 더블클릭하면 선택 목록을 엽니다. 한 번 클릭하면 셀만 선택합니다.

날짜 셀을 더블클릭하면 달력이 바로 열립니다. 달력에서 날짜를 선택하거나 입력칸에 `2026-10-13` 또는 `20261013`처럼 직접 입력할 수 있습니다. 직접 입력한 날짜는 Enter·Tab 또는 다른 셀 클릭으로 저장하고, Esc로 취소합니다. 입력칸에서 ↓를 누르면 달력으로 이동해 방향키와 Enter로 날짜를 선택할 수 있습니다.

저장·권한 변경·추가·삭제 등 작업 완료 안내는 화면 하단 토스트로 표시하며 4초 뒤 자동으로 사라집니다. 오류와 입력 검증 메시지는 해당 화면에 표시합니다.

| 입력 | 동작 |
| --- | --- |
| Enter | 저장 후 다음 행으로 이동 |
| Tab / Shift+Tab | 저장 후 다음 / 이전 셀로 이동 |
| Shift+Enter | 텍스트 줄바꿈 |
| Esc | 현재 편집 취소 |
| 다른 셀 클릭 | 입력 저장 후 선택 이동 |
| Shift+클릭 / 마우스 드래그 / Shift+방향키 | 여러 셀 선택 |

한글 조합 중 Enter는 저장 단축키로 처리하지 않습니다. 편집 중에도 행 높이는 유지합니다.

열 머리글을 클릭하면 해당 열 전체가, 왼쪽 행 번호를 클릭하면 해당 행 전체가 선택됩니다. 머리글·행 번호를 드래그하거나 Shift+클릭하면 연속된 여러 열·행을 선택합니다. 선택한 범위에 서식 도구의 글자 크기·배경색 등을 적용할 수 있습니다. 서식은 화면 밖의 행과 범위 안의 숨긴 행·열에도 적용됩니다. 행 전체 서식에는 숨긴 속성·날짜 열이, 열 전체 서식에는 숨긴 행이 포함되며, 업무 필터로 제외한 행은 포함하지 않습니다. 왼쪽 위 **#** 또는 **⌘/Ctrl+A**로 전체 선택한 뒤 적용하는 서식은 앞뒤의 숨긴 행·열까지 모두 포함합니다.

번호 칸은 **왼쪽 이동 손잡이 · 숨김 구간 화살표 · 행 번호 선택**로 나뉩니다. 이동 손잡이를 드래그하면 옮길 행이 흐리게 표시되고, 업무명과 삽입 위치선이 나타납니다. 행 번호를 드래그하거나 Shift+클릭하여 여러 행을 선택한 뒤, 선택한 행 중 하나의 손잡이를 끌면 기존 순서 그대로 함께 이동합니다. 숨기거나 필터로 제외한 행은 이동 대상에 포함하지 않습니다. Esc로 취소하면 기존 선택을 유지합니다. **묶음 보기에서는 같은 묶음 안에서만** 이동하며, 선택한 모든 행에 편집 권한이 있어야 합니다. 손잡이에 초점을 두고 Alt+위/아래 방향키로도 선택한 행들을 함께 옮길 수 있습니다. 컬럼 정렬 중에는 머리글 우클릭 메뉴에서 먼저 **정렬 해제**를 선택합니다.

행 번호를 우클릭하면 **위에 삽입·아래에 삽입·복사·복사한 행 붙여넣기·행 삭제**를 사용할 수 있습니다. 삽입은 우클릭한 행을 기준으로 새 업무를 만들고, 그 행의 모든 셀 서식(배경색·글자색·폰트·정렬·텍스트 표시·테두리)과 개별 행 높이를 상속합니다. 숨긴 속성·주차 열의 서식도 포함합니다. 업무 내용과 선택값은 비워 두며, 묶음 보기 중에는 같은 묶음에 머물도록 묶음 기준값만 유지합니다. 작업명 입력을 바로 시작하고, 이미 보이는 작업 열의 가로 위치는 유지합니다. 팀원 값도 미지정으로 두며, 팀원 속성으로 묶은 경우에만 지정 권한 안에서 해당 묶음 값을 유지합니다. 일반 팀원도 자신이 삽입한 미지정 업무는 편집할 수 있습니다. 붙여넣기는 그 행의 바로 아래에 추가합니다. 복사는 당시의 모든 속성·주차 일정·서식·문서 본문·개별 행 높이를 보관하며, 같은 팀·연도에서 사용할 수 있습니다. 팀·연도를 바꾸거나 새로고침하면 복사한 행은 초기화됩니다. 일반 팀원이 붙여넣은 업무는 본인 담당으로 생성됩니다. 행 삭제는 실행취소로 복원할 수 있습니다. 삽입·복사·붙여넣기는 한 행 선택 시 제공하며, 여러 행 선택 시 **행 삭제·행 숨기기**를 사용할 수 있습니다. Shift 또는 ⌘/Ctrl로 선택한 모든 보이는 행을 함께 삭제하고 한 번의 실행취소로 복구합니다. 선택한 모든 행에 편집 권한이 있어야 하며 한 행이라도 충돌하면 전체 삭제를 취소합니다. 삽입·붙여넣기 후 새 행을 볼 수 있도록 정렬과 속성 필터를 해제합니다.

같은 메뉴에서 **업무 상세**를 선택하면 제목과 넓은 문서 편집 영역이 먼저 열립니다. 제목과 그 아래 한 줄 설명을 별도 수정 버튼 없이 바로 입력합니다. 나머지 속성은 이름·값 두 줄의 가로 목록으로 표시합니다. 선택값·담당자·지원자는 값을 누르면 즉시 목록이 열리고, 날짜는 달력 또는 직접 입력으로 바꿉니다. 입력은 자동 저장하며 닫기·업무 동작 전에 저장을 마칩니다. 실패하면 입력을 유지하고 **저장 다시 시도** 또는 **입력 취소**를 제공합니다. 숨긴 열의 속성도 표시하며, 속성이 많거나 화면이 좁으면 가로로 스크롤합니다. 숨기기·복제·다음 연도 표시·업무 삭제 버튼은 상세 창 오른쪽 상단, 닫기 버튼 왼쪽에 있습니다. 사본도 즉시 편집하고 자동 저장합니다. 좁은 화면에서는 일반 업무 버튼을 아이콘으로 표시하며 툴팁으로 이름을 확인합니다. 전체 페이지 보기에서도 상단 버튼을 사용할 수 있습니다. 다음 연도에도 표시한 업무는 같은 ID와 일정을 공유합니다.

⌘(Mac)/Ctrl(Windows)을 누른 채 셀·머리글·행 번호를 클릭하거나 드래그하면 떨어진 영역을 추가 선택합니다. 일반 클릭은 새 선택으로 바꾸며 Esc는 전체 선택을 해제합니다.

### 업무 문서

상단 **문서 브라우저**에서 선택한 팀·연도의 원본과 사본 문서를 모아 볼 수 있습니다. 범위와 속성별 묶음을 선택하고 **작업 이름**으로 검색합니다. 작업 이름을 누르면 첫 문서가 열리며, 목록의 개별 문서를 누르면 해당 문서를 바로 편집합니다. 문서 제목 옆에는 본문 미리보기를 표시합니다. 원본과 사본은 각각 자동 저장하며 다른 작업이나 화면으로 이동하기 전에 현재 입력을 저장합니다.

문서가 없는 업무는 상세 화면 중앙에 캐릭터와 Markdown 문서 안내를 표시합니다. **문서 작성** 버튼을 누르면 편집기가 열립니다. 작성된 내용이나 보관된 미저장 초안이 있으면 바로 문서를 엽니다. 열람자는 문서가 없다는 안내만 확인합니다. 업무 상세의 문서 제목 탭을 눌러 문서를 전환합니다. 오른쪽 **+**로 문서를 추가하며 업무마다 최대 50개를 만들 수 있습니다. 제목을 더블클릭하거나 F2 또는 **문서 메뉴 → 문서 이름 변경**으로 탭 안에서 이름을 바로 수정합니다. 입력 상자 폭은 입력한 글자 길이에 맞춰 늘어나며 최대 50자까지 입력합니다. Enter 또는 다른 곳을 누르면 저장하고 Esc로 취소합니다. 10자 이상인 제목은 탭에서 앞 9자와 …로 줄여 표시하며, 마우스를 올리거나 편집하면 전체 제목을 확인할 수 있습니다. 제목이 많으면 트랙패드 좌우 제스처로 스크롤하며, 양 끝에서도 브라우저 뒤로가기·앞으로가기로 이어지지 않습니다. 같은 메뉴에서 선택한 문서만 삭제합니다. 메뉴 바깥을 클릭하거나 Esc를 누르면 메뉴가 닫힙니다. 키보드 초점을 메뉴 밖으로 옮겨도 닫힙니다. 입력은 자동 저장하며 탭 전환·상세 닫기 전에 현재 입력을 저장합니다. 본문이 있는 문서가 하나라도 있으면 작업명 셀 오른쪽 위에 작은 문서 아이콘을 표시합니다. 문서가 2개 이상이면 아이콘 옆에 전체 문서 수를 작은 숫자로 표시합니다(빈 문서 탭 포함).

기본은 **리치 문서**입니다. 문서 제목 줄 오른쪽 **문서 메뉴(…) 옆의 `<>` / 연필 토글**로 Markdown 원문과 리치 문서를 전환합니다. 리치 편집의 저장 상태는 툴바 맨 오른쪽 실행취소·재실행 버튼 왼쪽에 표시하며, Markdown 원문과 읽기 전용에서는 문서 제목 줄에 표시합니다. 문서 제목 탭·모드 토글·리치 툴바는 스크롤해도 상단에 유지됩니다. Markdown 원문 입력창은 팝업의 남은 높이를 채우며, 긴 원문은 입력창 안에서 스크롤합니다. 창 크기 변경과 전체 페이지 보기에도 높이가 맞춰집니다. 업무 상세 제목 오른쪽의 펼치기 아이콘으로 전체 페이지를 열어도 제목·설명·속성이 유지됩니다. 원문과 리치 본문의 기본 글꼴은 **Pretendard 15px**입니다. 제목·목록·인용·코드·굵게·기울임·취소선·링크·체크리스트·표와 Markdown 단축 입력을 지원합니다. 문서 안의 ⌘/Ctrl+Z와 Shift+⌘/Ctrl+Z는 문서 입력만 실행취소·재실행합니다.

툴바의 **취소선** 아이콘으로 선택한 글자에 취소선을 적용하거나 해제할 수 있습니다. **글머리 목록·번호 목록·체크리스트** 아이콘으로 목록을 만들 수 있습니다. **문서 실행취소·문서 재실행** 버튼은 되돌리거나 다시 적용할 편집 이력이 있을 때만 활성화됩니다.

표의 열 너비는 내용에 맞춰 자동으로 배분됩니다. 같은 셀 안에서 줄을 바꾸려면 **Shift+Enter**를 누릅니다. Markdown 원문에서는 `첫 줄<br />다음 줄`처럼 입력합니다. 표 안의 셀을 선택하면 툴바에서 **표 행 +·표 열 +·표 행 -·표 열 -·표 삭제**를 사용할 수 있습니다. 행·열 삭제는 선택한 셀의 행·열에 적용하며, 마지막 열을 삭제하면 표 전체가 삭제됩니다. 머리글 행과 마지막 본문 행은 유지하며, 표를 없애려면 **표 삭제**를 사용합니다. 툴바 맨 오른쪽의 문서 실행취소로 삭제를 되돌리고, 재실행으로 다시 적용할 수 있습니다.

리치 문서에서는 **⌘/Ctrl+C**, **⌘/Ctrl+V**로 표와 텍스트를 함께 복사·붙여넣을 수 있습니다. 제목·글자 서식·링크·목록·체크리스트와 표의 정렬·줄바꿈을 유지하며, 붙여넣은 내용도 실행취소·재실행할 수 있습니다. 코드 블록 안에서는 복사한 내용을 코드 텍스트로 붙입니다.

리치 편집에서 공백·목록 기호·표 정렬 문자가 정규화될 수 있습니다. 조회나 모드 전환만으로 저장된 원문을 바꾸지는 않습니다. 빈 줄용 `<br />`는 줄바꿈으로 표시하고 코드 안의 태그는 글자로 표시합니다. 안전하게 왕복할 수 없는 HTML·외부 이미지·각주 등의 구문은 원문을 유지하며 전환 이유를 안내합니다.

리치 문서에 이미지를 **붙여넣거나 끌어 놓으면** 서버에 업로드해 삽입합니다. PNG·JPEG·WebP 정지 이미지, 파일당 10MiB·4천만 화소까지 지원하고 긴 변 4096px 이내의 WebP로 저장합니다. 이미지 오른쪽 아래 손잡이로 비율을 유지하며 크기를 바꾸고, **이미지 크게 보기** 또는 더블클릭으로 확대합니다. 확대 창의 **실제 크기 / 화면에 맞추기**를 사용할 수 있으며 Esc는 확대 창만 닫습니다. 업로드가 끝나기 전에는 탭 전환·닫기를 기다립니다.

원본과 각 사본의 문서 목록·제목·본문은 독립적입니다. 원본을 수정해도 이미 만든 사본은 바뀌지 않고, 한 사본에서 문서를 추가·수정·삭제해도 다른 사본에 영향을 주지 않습니다. 별도의 문서 분기 정보 화면은 제공하지 않습니다.

문서 로딩 중에는 중앙의 캐릭터 ‘그래’ 가슴 네 칸을 순서대로 밝히고, 준비가 끝나면 도구와 본문을 함께 표시합니다. 앱 초기화·업무표 조회·XLSX 처리·감사 로그·저장 용량 첫 조회에도 같은 캐릭터를 사용합니다. 동작 줄이기 설정에서는 정지된 모습으로 표시합니다.

저장 오류가 나면 입력을 유지하고 **저장 다시 시도**를 제공합니다. 동시 수정 충돌은 최신 서버 문서를 확인한 뒤 처리합니다. **초안 보관하고 닫기**는 현재 브라우저 세션에 해당 원본/사본·업무·문서별 초안을 보관합니다. 열람자는 리치/원문을 읽을 수 있으나 문서를 수정할 수 없습니다.

## 2. 서식과 복사

서식 도구에서 글자색·배경색, 글꼴, 6~36pt 크기, 가로·세로 정렬, 굵게·기울임·밑줄·취소선을 지정합니다. **⌘/Ctrl+B**는 선택한 모든 영역의 굵게를 켜거나 끕니다. 셀 입력 중에도 입력 내용을 유지하며 해당 셀에 적용합니다. 여러 셀에 서로 다른 서식이 섞여 있어도 메뉴의 현재 값을 다시 선택하면 전체 선택 범위에 적용됩니다.

행 전체에 지정한 배경색·글꼴 등은 앞으로 표시할 주차에도 이어집니다. 같은 업무를 다음 연도에 표시해도 유지되므로 12월에서 다음 해 1월·2월로 이동할 때 다시 지정할 필요가 없습니다. 열 전체 서식은 선택한 날짜·속성 열과 선택 당시 필터에 포함된 업무에 적용됩니다.

전체 서식을 지정한 뒤 한 셀의 배경색만 바꾸면 그 셀만 다른 색이 되고 글꼴 등은 전체 서식을 유지합니다. 같은 행·열에 배경색을 다시 지정하면 셀마다 바꾼 배경색도 새 색으로 맞춥니다. 행·열 서식이 겹치면 각 항목에 마지막으로 지정한 값이 적용됩니다.


| 설정 | 기본값 / 동작 |
| --- | --- |
| 새 팀 글자 크기 | 9pt |
| 팀 기본 셀 높이 | 편안하게 |
| 왼쪽 열 고정 | 고정 안 함 |
| 셀 좌우 여백 | 일반·날짜·주간 일정 셀 모두 4px |
| 글꼴 | Noto Sans KR, Pretendard, 맑은 고딕, Noto Serif KR, Nanum Gothic Coding |
| 셀 높이 | 넉넉하게·편안하게·촘촘하게. 촘촘하게는 편안하게의 약 2/3 |

맑은 고딕은 설치된 글꼴을 사용하고, 없으면 Pretendard로 표시합니다. 기존 업무에 저장된 서식은 기본값 변경으로 일괄 수정되지 않습니다.

**텍스트 표시**는 다음 세 가지를 제공합니다.

- **오버플로우**: 기본 동작입니다. 오른쪽의 연속된 빈 셀까지 표시하고 다음 값 또는 고정 영역 경계에서 자릅니다.
- **줄바꿈**: 셀 너비에 맞춰 여러 줄로 표시합니다.
- **자르기**: 자신의 셀 끝에서 말줄임표 없이 자릅니다.

세로 정렬과 텍스트 표시 버튼은 현재 설정의 아이콘을 보여 줍니다. 버튼을 누르면 세 가지 아이콘이 가로로 펼쳐지고, 아이콘에 마우스를 올리면 이름을 확인할 수 있습니다. 줄바꿈과 위·중간·아래 정렬은 별도로 설정합니다. 여러 줄 내용이 셀 높이를 넘으면 첫 줄부터 표시합니다. 열 경계와 번호 열의 아래 경계를 끌어 너비·높이를 조절할 수 있습니다.

**테두리** 버튼에서 선 스타일·색상을 정한 뒤 위치를 고릅니다. 윗줄은 **모든 테두리**, **안쪽 테두리**, **가로 안쪽 테두리**, **세로 안쪽 테두리**, **바깥쪽 테두리**이고, 아랫줄은 **왼쪽**·**위쪽**·**오른쪽**·**아래쪽 테두리**와 **테두리 지우기**입니다. 왼쪽·오른쪽처럼 한 방향만 고르면 선택 영역의 그 방향 외곽에만 선을 긋습니다. **스타일 → 기본 테두리**를 선택한 뒤 위치를 누르면 해당 위치만 옅은 기본 격자선으로 되돌립니다. **스타일 → 없음**은 해당 위치의 기본 격자선까지 숨깁니다. 두 기능 모두 다른 방향의 테두리는 유지하며 안쪽·바깥쪽 테두리에도 적용할 수 있습니다. 떨어진 영역은 각각 적용하고, 맞닿거나 겹친 영역은 합쳐진 선택을 기준으로 바깥과 안쪽을 나눕니다. **테두리 지우기**는 모든 방향을 기본 격자선으로 되돌립니다. 실행취소·재실행을 지원합니다. 행 전체의 안쪽 선은 새 주차에도 이어지며, 직접 지정한 왼쪽·오른쪽 끝선은 지정 당시의 열에 남습니다.

**⌘/Ctrl+C**, **⌘/Ctrl+V** 단축키로 내용과 셀 서식을 함께 복사·붙여넣기합니다. 한 번에 2,000셀까지 처리하고 빈 셀의 배경색도 유지합니다. 일반 텍스트를 붙이면 대상 셀의 기존 서식을 유지합니다. 셀 내부 편집 중에는 텍스트만 붙여넣습니다. 숨기거나 필터에서 제외한 행은 값 편집·복사·붙여넣기에서 제외됩니다. 개별 셀 범위의 서식은 숨긴 행·열을 포함하여 한 번에 50,000셀까지 지원합니다. 행·열 전체 선택은 개별 셀 범위와 별도로 한 번에 서식을 적용합니다. 배경색·테두리를 비롯한 모든 서식과 실행취소·재실행에 같은 기준을 사용합니다.

복사·붙여넣기는 하나의 연속된 영역에서 사용합니다. 셀 테두리도 HTML·앱 클립보드와 XLSX 반출·이관에 포함합니다.

외부 HTML 표는 지원하는 셀 단위 서식만 가져옵니다. 셀 병합과 셀 내부 부분 서식은 지원하지 않습니다. 수식처럼 보이는 문자열은 계산하지 않고 텍스트로 저장합니다. 여섯 자리 이슈 번호는 설정된 Redmine 주소의 링크로 표시합니다.

## 3. 기간과 보기

최상단에서 팀을 선택하고 오른쪽의 연간 업무·변경 이력·설정·내 계정 메뉴를 사용합니다. 원본·사본 탭과 **+ 사본 추가** 버튼은 표 하단에 있습니다. 하단 탭의 가로 스크롤은 양 끝에서 브라우저 뒤로가기·앞으로가기로 이어지지 않습니다. 사본에서도 **가져오기·내보내기** 버튼을 그대로 사용합니다. 사본에서 가져온 XLSX 업무는 현재 사본에 추가하며, 내보내기는 해당 사본의 업무·속성·서식·문서를 기준으로 합니다. 원본으로 전환하려면 하단 **원본** 탭을 선택합니다. 우측 상단의 이름을 누르면 **프로필·비밀번호 변경·로그아웃** 하위 메뉴가 열립니다. **프로필**에서 표시 이름, 아바타 이미지, 직접 입력한 이니셜(영문·숫자 1~3자 또는 한글 1~2자), 배경색을 설정합니다. PNG·JPEG·WebP 이미지는 5MB까지 선택할 수 있으며 중앙을 정사각형으로 맞춥니다. 저장하면 상단 이름과 팀원 셀에도 반영됩니다. 로그인 아이디(이메일)는 이 화면에서 변경하지 않습니다. **비밀번호 변경**에서는 현재 비밀번호와 새 비밀번호(10~128자), 비밀번호 확인을 입력하며 새 비밀번호와 확인이 일치해야 저장됩니다. 왼쪽 메뉴와 하단 안내 영역은 표시하지 않습니다.

달력 왼쪽의 **〈 연도 〉** 화살표는 항상 **한 해의 1~12월 전체**로 이동합니다. 단일 연도에서는 이전·다음 해로 이동하고, `2026~2027`처럼 두 해가 걸치면 왼쪽은 **2026년 전체**, 오른쪽은 **2027년 전체**를 선택합니다. 이전에 저장한 월 범위가 있어도 연도 화살표를 누르면 날짜 선택과 숨김을 초기화하고 해당 연도의 표 배치를 복원하며 현재 필터 조건은 유지합니다. 제목의 **연간 업무 2026**에는 기준 연도만 표시합니다. 달력 양 끝에 붙은 같은 폭의 작은 화살표는 **항상 12개월인 구간을 한 달씩** 이동합니다. 예를 들어 2026년 1~12월에서 오른쪽을 누르면 **2026년 2월~2027년 1월**이 됩니다. 월 이동으로 두 해가 걸치면 왼쪽 연도는 `2026`과 `~2027` 두 줄로 표시합니다. 연도 숫자를 누르면 현재 달력의 12개월 전체를 선택합니다. 표시 범위는 2000년 1월부터 2100년 12월까지입니다.

표시 구간에 해당하는 최대 두 연도의 업무를 함께 조회하며, 같은 업무는 한 행만 표시합니다. **업무 추가·행 삽입·복제는 제목에 표시된 기준 연도**로 등록합니다. 2027년 1~12월로 완전히 이동하면 기준 연도도 2027년으로 바뀝니다. 달력 이동은 업무의 표시 연도를 바꾸지 않으며, 이어지는 업무는 기존 **다음 연도에서도 표시** 기능으로 연결합니다. 달력 양 끝의 월 이동 화살표를 눌러도 선택한 월·주차가 새 구간 안에 있으면 그대로 유지됩니다. 선택 범위가 구간 밖으로 나갈 때만 같은 개월 수·주 수를 유지해 가장 가까운 범위로 함께 이동합니다. 예를 들어 11~12월을 선택한 뒤 계속 오른쪽으로 이동하면 11월이 사라질 때 12월~다음 해 1월로 옮겨집니다. 반대 방향도 같은 규칙을 적용하며, 12개월 전체를 선택한 경우에는 이동한 12개월 전체를 유지합니다. 업무 필터·숨긴 행·속성 열·크기는 유지됩니다. 이동한 시작 월과 선택 범위도 개인 보기에 저장됩니다.

연도 옆의 작은 2행 표에서 기간을 선택합니다. 첫 행은 **시작 월부터 연속된 12개월**이며, **1월에만 `2026년 1월`처럼 연도를 함께** 표시합니다. 둘째 행은 각 월에 속한 실제 주차를 순서대로 표시합니다. 월 칸을 클릭하면 한 달, 드래그하면 연속된 여러 달을 선택합니다. 주차 칸에서도 같은 방식으로 한 주 또는 연속된 여러 주를 선택할 수 있으며, 월 경계를 넘어 드래그해도 됩니다. 역방향 드래그도 지원합니다. 월 또는 주차 버튼에 초점을 두고 방향키로 이동하거나 Shift+방향키로 범위를 늘릴 수 있습니다. Home·End는 처음·끝으로 이동하고 Esc는 진행 중인 드래그를 취소합니다. 첫 월부터 마지막 월까지 선택하면 현재 12개월 전체가 표시됩니다. 12월에서 다음 해 1월로 이어지는 드래그도 가능합니다.

기간을 새로 선택하면 선택한 주차를 표시하고 나머지 날짜 구간은 숨깁니다. 월·주차 드래그 중과 선택 완료 후에는 선택된 모든 주차 칸에 테두리가 표시됩니다. 이번 주는 선택 여부와 관계없이 주차 칸 위쪽의 굵은 선으로 구분합니다. 업무 필터와 숨긴 행·속성 열은 유지합니다. 달력의 선택 표시는 실제 보이는 날짜 열과 일치하며, 열 숨기기나 숨김 화살표로 펼친 결과도 반영됩니다. 팀·연도 전환과 기간 선택 후에는 표가 맨 왼쪽 업무 열에서 시작합니다.

상단의 **전체 속성 검색**은 현재 팀·표시 기간에서 컬럼 필터에 해당하는 업무의 작업·팀원·상태·사용자 정의 속성을 검색합니다. 팀원과 선택 항목은 화면에 표시되는 이름으로 찾으며 영문 대소문자를 구분하지 않습니다. 숨긴 행도 포함하고, 숨긴 열·삭제한 속성·주차 일정 셀은 제외합니다.

검색창 맨 왼쪽의 **›** 버튼을 누르면 아래로 **검색 대상 속성** 목록이 펼쳐집니다. 기본값은 표시된 열 전체 선택이며, 체크한 속성 안에서만 검색합니다. **전체 선택** 체크박스로 모두 선택하거나 해제할 수 있고, 아무 속성도 선택하지 않으면 결과는 0개입니다. 검색어가 입력된 상태에서 대상을 바꾸면 결과 개수와 첫 결과 위치가 갱신됩니다. Esc 또는 목록 바깥 클릭으로 접으며, 검색어를 지워도 속성 선택은 유지됩니다.

검색해도 업무 목록은 유지됩니다. **현재 순번 / 전체 결과 수**는 일치하는 셀을 기준으로 표시하고, 이전·다음 화살표 또는 검색창의 **Enter / Shift+Enter**로 순환 이동합니다. 숨긴 열은 검색에서 제외되며 검색 대상 목록에 취소선과 **숨김 · 검색 제외**로 표시됩니다. 숨긴 행의 결과로 이동하면 해당 행을 펼칩니다. 검색창의 **Esc** 또는 지우기 버튼으로 검색어를 지웁니다. 검색어와 검색 대상은 저장된 필터·사본에 저장하지 않으며, 새로고침이나 팀·연도·사본 전환 시 검색어를 비우고 전체 속성 선택으로 초기화합니다.

속성 열 머리글을 **우클릭 → 이 열로 묶음 보기**로 선택해 같은 값끼리 모읍니다. 다른 속성 열에서 같은 메뉴를 선택하면 묶음 기준이 바뀌고, **묶음 해제**로 원래 목록으로 돌아옵니다. 묶음 순서는 속성 탭의 값 순서를 따르며 미지정 값은 마지막입니다. 컬럼 머리글을 **우클릭**하면 **열 숨기기·여기까지 열 고정·열 고정 해제·오름차순 정렬·내림차순 정렬·정렬 해제**와 해당 컬럼의 **필터**가 열립니다. **정렬 해제**는 현재 정렬된 컬럼에서만 활성화됩니다. 여러 열을 선택한 채 우클릭하면 선택을 유지하며, 숨기기는 선택 열에, 정렬과 필터는 우클릭한 열을 기준으로 적용합니다. 작업 열은 숨기지 않으며 주차 날짜 열에는 정렬·필터를 제공하지 않습니다. 행 번호 우클릭에서는 선택한 행을 숨길 수 있습니다. 머리글에 초점을 두고 Shift+F10으로도 메뉴를 열 수 있습니다.

컬럼 필터는 값을 검색하여 여러 개 선택할 수 있습니다. 필터 하단 왼쪽의 **일치**는 선택한 값에 해당하는 업무만 표시하고, **제외**는 해당 업무를 빼고 표시합니다. 예를 들어 상태 컬럼을 우클릭해 **완료**를 선택하고 **제외**로 바꾸면 완료한 업무만 숨깁니다. **미지정**도 선택할 수 있으며, 선택 값이 없으면 전체를 표시합니다. 같은 필터 안의 값은 OR, 서로 다른 필터는 AND로 적용합니다. 적용 중인 컬럼은 머리글의 필터 아이콘으로 확인하고, 팝업의 **필터 해제**로 조건을 지웁니다. 상단의 **전체 속성 검색**과 함께 사용할 수 있습니다. 팀원 조건은 팀원 열 머리글의 필터에서 선택합니다. 별도의 통합 팀원 필터는 제공하지 않습니다.

열은 머리글 우클릭 메뉴의 **열 숨기기**로 숨기고, 숨김 구간의 화살표로 다시 펼칩니다. 묶음 기준 컬럼은 머리글 왼쪽의 묶음 아이콘으로 확인합니다. **여기까지 열 고정**을 선택하면 앞쪽 업무 정보 열을 해당 열까지 고정하며 **열 고정 해제**로 풉니다. 주차와 날짜 뒤의 속성은 고정할 수 없습니다. **설정 → 팀 → 기본 서식**에서 기본 셀 높이를 설정하고 개별 행 높이는 유지합니다. 열 고정·숨김·크기·기간 등 표 배치는 사용자·팀·기준 연도별로 저장합니다.

**필터에는 연도 구분이 없습니다.** 현재 조건과 선택 상태는 사용자·팀별로 기억합니다. **저장된 필터**는 열 필터의 선택 값과 일치·제외 조건만 보관합니다. 적용·해제해도 행·열 숨김, 고정·너비·순서, 행 높이, 기간, 묶음과 정렬은 유지됩니다.

**현재 필터 저장**을 누르면 이름 입력칸에 바로 입력할 수 있습니다. 팀장은 **개인용**(기본)과 **팀 공용**을 선택할 수 있습니다. 개인용은 본인에게만 보이며 본인만 수정·삭제합니다. 팀 공용은 해당 팀을 볼 수 있는 모든 사용자에게 보이고 해당 팀의 팀장만 저장·수정·삭제할 수 있습니다. 팀장으로 배속되지 않은 시스템 관리자도 공용 필터는 읽기 전용입니다. 목록과 선택 표시줄에서 사람 아이콘과 **개인용**·**팀 공용** 태그로 구분합니다. 공용과 개인용은 같은 이름을 사용할 수 있으며, 같은 구분에서 이름을 변경할 때 중복 이름은 거절합니다.

저장된 필터 목록에서 항목을 선택하면 서식 툴바와 셀 머리글 사이에 이름이 표시되고 바로 옆에 **개인용**·**팀 공용** 아이콘과 태그가 붙습니다. 이어서 적용된 조건이 설정의 속성 순서대로 나열되며, 숨긴 열의 조건도 표시됩니다. 각 조건을 누르면 선택 값·일치/제외 방식을 바로 바꾸거나 해당 필터를 해제할 수 있습니다. 해제한 조건도 현재 필터 보기를 닫기 전까지는 **속성명: 전체 표시** 버튼으로 남아 다시 설정할 수 있습니다. **전체 표시**를 누르면 값을 다시 선택할 수 있으며, 선택 값이 비어 있는 동안에는 업무를 거르는 조건에서 제외됩니다. **X(필터 보기 종료)**로 닫았다 다시 열거나 새로고침하면 해제한 조건의 버튼은 사라집니다. 상단 버튼은 항상 **저장된 필터**이고 목록은 항목 선택만 제공합니다. 일반 열 필터를 적용하거나 같은 조건을 만드는 것만으로는 표시줄이 나타나지 않습니다. 수정 권한이 있는 항목을 선택한 상태에서 표시줄이나 열 머리글의 필터를 변경하면 그 항목이 자동으로 업데이트됩니다. 조건 선택 UI 바로 오른쪽에 저장 중·완료·실패를 안내합니다. 저장이 끝나면 **필터 변경사항이 업데이트되었습니다.**라고 표시하며, 조건을 해제한 경우에는 **해제한 필터는 저장된 필터에서 제외됩니다.**라고 안내합니다. 표시줄의 **이름 변경**으로 이름을 바꾸며 기존 이름이 선택되어 바로 입력할 수 있습니다. **삭제** 후 알림의 **실행취소**로 복원할 수 있습니다.

팀원이 공용 필터를 선택하면 **읽기 전용**으로 표시하고 이름 변경·삭제 버튼은 제공하지 않습니다. 열 필터 조건을 직접 바꾸면 공용 선택이 해제되고 본인의 현재 조건으로 사용합니다. 공용 원본은 유지되며 바꾼 조건을 개인용으로 저장할 수 있습니다. 다른 항목을 선택하거나 표시줄의 **X(필터 보기 종료)**를 눌러도 저장된 조건은 변경하지 않습니다. X는 현재 열 필터를 지우고 표시줄을 닫습니다. 삭제 후에는 적용 조건을 유지하고 선택만 해제하며, 복원한 항목은 목록에서 다시 선택합니다. 사본은 당시 업무 값·서식·보기의 별도 사본입니다. 행·열 경계의 화살표로 숨김을 해제해도 필터는 유지됩니다.

행을 숨겨도 나머지 행 번호는 유지됩니다. 이동 손잡이와 행 번호 사이의 작은 삼각형을 누르면 해당 구간만 펼칩니다. 손잡이 오른쪽의 빈 부분도 행 선택 영역이며, 실제 삼각형 버튼을 누른 경우에만 숨김을 해제합니다. 맨 위·아래 구간과 전체 행을 숨긴 경우에도 펼치기 버튼을 제공합니다. 컬럼 필터로 제외된 행에는 숨김 표시를 만들지 않습니다.

숨긴 속성·주차 열은 머리글 경계 위쪽에 **좌우 화살표**로 표시합니다. 화살표 전용 열이나 빈 칸을 추가하지 않으므로 보이는 열은 바로 맞닿습니다. 달력에서 선택하지 않은 날짜와 접은 월도 동일한 숨김 구간으로 표시합니다. 화살표를 누르면 해당 연속 구간만 펼치고 다른 숨김 구간은 유지합니다. 맨 앞·뒤 구간도 복원할 수 있으며, 날짜 열을 모두 숨긴 경우에는 이어진 연간 전체 날짜를 펼칩니다. 별도의 숨긴 주차 목록 영역은 표시하지 않습니다.

## 4. 설정: 팀·구성원·속성·계정

상단의 **설정**은 시스템 관리자와, 한 팀 이상의 팀장에게 표시됩니다. 왼쪽 목록에서 대상을 고르면 오른쪽에 그 대상의 설정만 표시됩니다. 처음 열면 지금 보고 있는 팀이 선택되어 있습니다.

| 왼쪽 목록 | 오른쪽 내용 |
| --- | --- |
| 팀 (팀 이름) | 그 팀에만 적용되는 네 탭. 팀장은 자신이 팀장인 팀만 보입니다 |
| 새 팀 (시스템 관리자) | 팀 이름·시작 양식·테마를 정해 팀을 만들고, 바로 구성원 탭으로 이동 |
| 시스템 › 사용자 계정 (시스템 관리자) | 계정 추가·수정·활성화, 비밀번호 재설정, 시스템 권한, 소속 팀·팀 내 권한 확인 |
| 시스템 › 변경 이력 정리 (시스템 관리자) | 팀별 저장 용량 확인, 팀·날짜를 선택해 이전 이력 정리 |

| 팀 탭 | 기능 |
| --- | --- |
| 일반 | 팀 이름·테마, 팀 삭제(시스템 관리자) |
| 구성원 | 기존 사용자 추가, 팀 내 권한(팀장·팀원·열람자) 변경, 팀에서 제외 |
| 속성 | 이름·종류·표시·순서·선택값·색상·컬럼 표시 여부 |
| 기본 서식 | 공통 서식 툴바, 팀 기본 셀 높이, 적용 결과 미리보기 |

팀을 바꿔도 보고 있던 탭이 유지되어 여러 팀의 같은 설정을 차례로 확인할 수 있습니다. 사용자 계정 목록의 소속 팀 칩을 누르면 해당 팀의 구성원 탭으로 이동합니다. 팀장이 자신의 팀장 권한을 해제하거나 자신을 제외하면 확인 후 해당 팀을 더 이상 관리할 수 없습니다.

**기본 서식**은 표와 같은 툴바에서 글꼴·크기·강조·색상·정렬·텍스트 표시·테두리를 설정하고 아래 미리보기로 확인한 뒤 저장합니다. 서식은 새 업무와 해당 업무의 빈 일정 셀에 적용되며 기존 업무의 서식은 유지됩니다. 셀 높이는 팀 전체의 기본값입니다.

로그인 아이디는 **이메일 주소**입니다. 대소문자를 구분하지 않으며 소문자로 저장합니다. 이메일 형식이 아닌 기존 아이디도 그대로 로그인할 수 있고, 사용자 수정에서 이메일을 입력하면 그 주소로 바뀝니다. 비워 두면 기존 아이디를 유지합니다.

사용자 추가·수정의 **프로필 아바타**에서 이름 첫 글자(기본), 영문·숫자 1~3자 또는 한글 1~2자 직접 입력, 이미지 업로드 중 하나를 선택합니다. 배경색도 지정할 수 있습니다. 이미지는 5MB 이하의 PNG·JPEG·WebP를 사용하며 중앙을 정사각형으로 맞춥니다. 이름 첫 글자로 전환하면 업로드 이미지를 지울 수 있습니다.

팀에서 제외된 팀원도 기존 업무에는 최신 이름·아바타·배경색으로 표시됩니다. 필터와 새 담당자 선택 목록에서는 제외됩니다. 기존 배정을 다른 값으로 바꾸거나 해제한 뒤에는 다시 선택할 수 없습니다. 사본은 저장 당시 이름과 현재 아바타를 표시하며, 사본 편집에서는 보관된 팀원을 다시 선택할 수 있습니다.

새 팀은 **작업·팀원·상태** 세 속성을 만듭니다. 새 팀의 **시작 양식**에서 다른 팀을 선택하면 속성·선택값·표시·순서·기본 서식·테마를 복사합니다. 업무와 구성원은 복사하지 않습니다.

**속성** 탭에서 **주차 날짜**를 선택하면 날짜 열 **머리글의 배경색과 글자색**을 지정할 수 있습니다. 속성 저장 후 팀 전체에 적용되며, 이번 주와 선택한 열은 강조색으로 표시합니다. **기본값**을 누르고 저장하면 원래 색으로 돌아갑니다. 날짜 묶음의 양 끝에 항상 표시할 선은 같은 화면의 **기본 경계선**에서 지정합니다.

테마는 민트·하늘·라벤더·로즈·샌드 중 선택합니다. 팀 메뉴·버튼·선택 강조는 사본에서도 현재 팀 테마를 따르며, 업무 셀과 속성 칩의 개별 색상은 유지합니다. 저장된 필터나 사본을 열면 보기 표시줄·열 머리글·왼쪽 행 번호에 현재 팀 테마별 보조색을 적용합니다. 필터와 사본은 서로 다른 색으로 구분합니다. 사본을 닫으면 진입 직전의 필터 보기와 색상으로 돌아가며, 적용된 필터가 없었다면 원래 머리글 색으로 돌아갑니다.

팀 **일반** 탭 아래의 **팀 삭제**는 확인 후 팀의 모든 연도 업무·일정·사본·보기·이력·설정 등을 영구 삭제합니다. 이 동작은 앱에서 복구할 수 없습니다. 사용자 계정과 다른 팀의 데이터는 유지합니다.

### 속성과 상태 통계

| 종류 | 입력과 표시 |
| --- | --- |
| Option | 일반 텍스트·원형 칩·사각형 칩·포인트 칩·이모지 칩 |
| Text | 일반 텍스트 |
| Date | 날짜 |
| Number | 숫자 |
| Member | 단일·복수 팀원, 텍스트·아바타 |

속성 이름·컬럼 순서를 변경하고 오른쪽 상단의 **속성 추가**로 새 속성을 만들 수 있습니다. 상단 목록은 실제 열 순서대로 가로로 배치됩니다. 속성 카드의 이름·손잡이·여백을 잡아 좌우로 끌거나 Alt+왼쪽/오른쪽 방향키로 순서를 바꾸고, 속성을 클릭하면 아래에서 편집합니다. 끄는 동안 들어갈 자리가 미리 표시되며, 목록의 좌우 끝으로 끌면 자동으로 스크롤됩니다. 마우스가 목록 위아래로 조금 벗어나도 이동할 수 있고, Esc로 취소합니다. **속성 저장**을 눌러 변경한 순서를 저장합니다. 선택값 목록은 왼쪽 손잡이 또는 Alt+위/아래 방향키로 순서를 바꿉니다. 값 추가·이름 편집 중에는 표의 열 너비가 유지됩니다. 선택값 이름은 최대 15자입니다. 값마다 표시 순서와 배경색을 정하며, 포인트 칩은 점 색상을 별도로 지정합니다. 이모지 칩에는 색상 설정이 없습니다.

상단 목록의 **주차 날짜**는 전체 날짜 열을 나타내며 처음에는 맨 오른쪽에 있습니다. 진척률·목표일 등의 속성을 **주차 날짜 오른쪽으로** 끌어 옮기고 **속성 저장**을 누르면 표에서도 마지막 날짜 뒤에 배치됩니다. 주차 날짜 항목 자체도 이동할 수 있습니다. 같은 쪽에 놓인 속성은 목록 순서를 따르며, 조회 기간을 줄이거나 월·주차를 숨겨도 뒤쪽 속성은 표시 중인 날짜 다음에 유지됩니다. 모든 주차를 숨겨도 속성 열은 남습니다. 이 배치는 팀 공통 설정이며 새 팀 양식·새 사본·내보내기에도 반영됩니다. 왼쪽 열 고정은 주차 날짜 앞의 표시된 업무 정보 열만 대상으로 합니다.

**설정 → 속성 → 주차 날짜 → 기본 경계선**에서 왼쪽·오른쪽의 선 모양과 색상을 각각 지정합니다. 현재 보이는 첫 날짜의 왼쪽과 마지막 날짜의 오른쪽에 적용되므로 기간을 줄이거나 날짜를 숨겨도 새 양 끝에 경계선이 유지됩니다. 날짜가 하나면 같은 열의 양쪽에 표시하며, 모든 날짜를 숨기면 표시하지 않습니다. 셀에서 별도로 그린 선이 우선하며 **테두리 지우기**를 하면 기본 경계선이 다시 표시됩니다. 기본 경계선을 없애려면 이 설정에서 **없음**을 선택합니다. **속성 저장**을 누르면 팀 전체에 적용되며 새 사본·내보내기에도 포함됩니다.

작업·팀원·상태는 삭제나 종류 변경이 불가능합니다. 이름과 표시 순서는 변경할 수 있습니다. 권한에 연결된 팀원과 지원자는 Member 종류 및 단일·복수 구성을 유지합니다. 지원자는 보관·복원이 가능합니다. 속성 삭제는 경고 후 보관 처리하며 기존 셀 값을 보존합니다. 저장 전 빈 초안은 바로 제거합니다.

상태는 예정·검토 중·진행 중·완료·보류를 기본 제공하고 활성 선택값이 하나 이상 필요합니다. 상단 통계는 상태 속성의 이름·값·색상·순서에 맞춰 **현재 달력에 해당하는 연도들의 전체 업무(중복 제외)**를 집계합니다. 필터·숨김과 무관하며, 빈 상태는 미지정, 보관된 선택값은 ‘보관된 값’으로 합산합니다.

### 권한

권한은 **시스템 권한**과 **팀 내 권한** 두 가지입니다. 시스템 권한은 계정마다 하나이고, 팀 내 권한은 팀마다 따로 정합니다. 같은 사람이 A팀에서는 팀장, B팀에서는 팀원일 수 있습니다.

| 시스템 권한 | 범위 |
| --- | --- |
| 시스템 관리자 | 계정 생성·비활성화·비밀번호 재설정, 팀 생성·삭제, 소속과 관계없이 모든 팀 관리 |
| 일반 사용자 | 소속 팀에서 팀 내 권한에 따른 작업 |

| 팀 내 권한 | 범위 |
| --- | --- |
| 팀장 | 팀 이름·테마·속성·기본 서식, 기존 사용자의 팀 추가·제외·권한 변경, 모든 업무 편집, 담당자 지정, 삭제 이력 복구·가져오기·사본 |
| 팀원 | 업무 등록, 자신이 담당하거나 지원하는 업무와 직접 등록한 미지정 업무 편집, 사본 생성·편집·삭제 |
| 열람자 | 조회·필터·개인 보기·내보내기 |

담당자와 Member 속성에는 그 팀의 팀장·팀원만 선택할 수 있습니다. 시스템 관리자도 팀에 소속되지 않으면 담당자 목록에 나타나지 않습니다. 팀장이 없는 팀도 시스템 관리자가 관리할 수 있습니다.

서버에서도 소속 팀과 권한을 검사합니다. UI에서 숨기는 것만으로 편집을 제한하지 않습니다.

## 5. 저장과 이력

셀 편집을 확정하면 입력한 내용을 셀에 즉시 표시하고 저장을 요청합니다. 짧은 저장에서 화면이 깜빡이지 않도록 **저장 중** 표시는 저장이 0.25초 이상 이어질 때 나타나고, 완료되면 사라집니다. 저장에 실패하면 즉시 **저장 실패**를 표시하며, 셀은 저장 전 내용으로 돌아갑니다. 입력한 내용은 **입력 확인**에서 다시 시도하거나 최신 버전을 확인한 후 재적용할 수 있습니다. 로그인 만료 시 재인증하여 입력을 복구합니다. 저장 중이거나 실패한 입력이 있으면 로그아웃을 제한합니다.

**변경 이력** 목록은 날짜·시각 왼쪽에 **10초 전**, **1분 전** 같은 상대 시간을 함께 표시합니다. 이력 창을 열어 둔 동안 상대 시간은 자동으로 갱신됩니다.

다른 사용자가 셀 값을 저장하면 같은 팀의 업무표에 실시간으로 반영합니다. 각자의 행·열 숨김, 적용 중인 저장된 필터, 열 너비·고정, 스크롤 위치는 유지됩니다. 숨긴 셀도 값은 갱신되며 직접 펼치면 최신 값이 보입니다. 필터 조건은 유지하고 변경된 값에 따라 표시 결과를 다시 계산합니다. 입력 중인 행은 편집을 마칠 때 필터 결과에 반영합니다. 연결이 끊기면 자동으로 재연결하여 누락된 변경을 복구합니다. 업무 추가·삭제·설정 등은 기존 주기 조회로 갱신합니다.

같은 셀을 동시에 수정하면 내 입력을 보존하고 버전 충돌을 안내합니다. 입력 중 다른 셀의 변경은 계속 반영됩니다.

**실행취소·재실행**은 현재 팀·기준 연도의 편집 세션에서 최근 **50개 작업**을 역순으로 처리합니다. 툴바 버튼 또는 **⌘/Ctrl+Z**, **⌘/Ctrl+Shift+Z**를 사용합니다.

실행취소·재실행 기록을 합쳐 최대 50개를 보관하며, 새 작업으로 한도를 넘으면 가장 오래된 기록부터 즉시 버립니다. 여러 셀을 한 번에 붙여넣거나 서식을 적용한 작업도 1개로 셉니다. 이 제한은 사용자별 편집 세션에 적용되며, 서버의 변경 이력 보관 개수와는 별개입니다.

- 대상: 저장한 셀 값·서식과 행·열 공통 서식 변경, 셀 붙여넣기·내용 지우기, 업무 추가·행 삽입·행 붙여넣기·복제·삭제.
- 업무 추가 취소는 해당 업무를 삭제 상태로 바꾸며, 재실행하면 같은 ID·내용·서식으로 복원합니다. 추가 후 제목을 입력했다면 첫 실행취소는 제목 입력을, 그다음은 업무 추가를 취소합니다.
- 저장 중이거나 저장 실패를 처리 중인 경우, 발표 모드에서는 업무 실행취소를 사용할 수 없습니다. 사본에서는 현재 편집 중인 사본만 별도로 실행취소·재실행합니다. 이후 변경과 충돌하거나 편집 권한이 없으면 되돌리지 않습니다. 추가한 업무에 다른 사용자의 수정이 있으면 추가 취소로 그 업무를 삭제하지 않습니다.
- 셀이나 입력란 안에서 ⌘/Ctrl+Z를 누르면 입력 중인 텍스트를 되돌립니다. 업무표 작업을 되돌리려면 편집을 마친 뒤 툴바 또는 단축키를 사용합니다. 추가 직후에는 툴바 실행취소로 바로 취소할 수 있습니다.
- 새로고침·로그아웃·팀 또는 기준 연도 전환 시 기록이 초기화됩니다. 실행취소 후 새 셀 편집·업무 추가·삭제를 저장하면 이전 재실행 기록을 비웁니다.
- 행 순서 이동·다음 연도 표시, 필터·정렬·숨김·크기 등 보기 변경, 프로필·비밀번호·팀 설정, 이관·보고본은 업무표 실행취소 대상이 아닙니다. 저장된 필터 삭제는 삭제 알림의 실행취소를 **8초 동안** 별도로 제공합니다.

원본과 사본에서 행을 삭제하면 8초 동안 알림에 **실행취소** 버튼이 표시됩니다. 여러 행도 한 번에 복구합니다. 다른 시트로 이동하거나 후속 편집을 하면 이전 삭제 알림은 닫히며, 현재 세션의 작업은 툴바 실행취소로도 되돌릴 수 있습니다. **변경 이력**은 현재 시트의 기록만 표시하며, 삭제 항목을 펼쳐 **삭제한 업무 복구**를 누르면 같은 시트로 복구합니다. 원본은 팀장·관리자가, 사본은 편집 권한이 있는 사용자가 복구할 수 있습니다. 사본에서는 행의 내용·서식·문서도 함께 복구합니다. 이미 복구했거나 이후 다시 삭제한 업무는 이전 삭제 이력으로 되돌리지 않습니다. 별도 휴지통 화면은 제공하지 않습니다. 이력을 정리하면 해당 이력을 통한 복구도 사용할 수 없습니다.

오프라인 편집 저장소는 제공하지 않습니다. 미저장 입력이 있을 때 탭을 닫으면 복구하지 못할 수 있습니다.

**설정 → 시스템 → 변경 이력 정리**는 시스템 관리자만 사용할 수 있습니다. 먼저 팀별 전체 데이터·변경 이력·사본 용량을 비교하고 **팀을 선택**합니다. **기준 날짜**를 지정한 뒤 **데이터 용량 확인**을 누르면 그 날짜의 **한국 시간 00:00 이전**에 저장된 이력의 건수·용량과 삭제 가능한 양이 표시됩니다. 처음에는 365일 전 날짜를 제시하며 30·90·180·365일 전 버튼이나 바로 옆 날짜 입력란으로 날짜를 선택할 수 있습니다.

**이전 데이터 삭제**에서 팀·날짜·건수·용량을 확인한 뒤 해당 팀의 이력만 삭제합니다. 팀이나 날짜를 바꾸면 용량을 다시 확인해야 합니다. 아직 저장 재시도에 필요한 기록은 자동으로 보호합니다. **중단** 후 남은 용량을 확인해 계속할 수 있으며 최근 정리 결과도 팀별로 확인합니다. 현재 업무·사본·백업·다른 팀 이력과 최대 50회 실행취소는 유지됩니다. 자동 삭제는 하지 않습니다. **시스템 공통**은 팀이 없는 공통 이력과 여러 팀이 공유하는 재시도 기록만 별도로 관리합니다.

저장 요청의 재시도 유효기간은 최초 요청부터 7일입니다. 기간이 지나면 입력을 복사해 보관하고 **입력 취소·최신 내용 보기**로 현재 업무를 확인한 뒤 다시 편집합니다.

### 시스템 감사 로그

로그인 성공과 직접 로그아웃한 기록도 조회할 수 있습니다. **작업 종류 → 로그인 / 로그아웃**으로 필터링하면 해당 사용자와 시각을 확인할 수 있습니다. 새로고침이나 기존 세션 복원은 새 로그인으로 기록하지 않습니다.

시스템 관리자는 **설정 → 시스템 → 감사 로그**에서 계정 생성·수정, 권한·소속 변경, 프로필·비밀번호 변경, 팀 삭제와 공통 이력 정리 기록을 조회합니다. **시작 날짜·종료 날짜·수행자·작업 종류**를 선택하고 **조회**를 누릅니다. 처음 열면 시작·종료 날짜가 한국 시간 기준 **오늘**로 설정되어 오늘 기록을 조회합니다. 날짜 범위는 양 끝 날짜를 포함하며, 기간을 비우면 보관 중인 전체 기간을 조회합니다. **초기화**는 오늘 날짜로 돌아가고 수행자·작업 종류 조건을 해제합니다.

로그는 최신순으로 **한 페이지에 50건**씩 표시하고 **이전·다음**으로 이동합니다. 항목을 펼치면 변경 전·후 값을 확인할 수 있습니다. 수행자·대상 이름은 현재 계정 정보를 사용하고, 전후 값은 당시 저장된 기록입니다. 팀 업무 변경은 기존 **변경 이력**에서 조회하며, 공통 저장 재시도 기록은 감사 로그 목록에 포함하지 않습니다. 이미 정리한 로그는 조회되지 않습니다.

## 6. 사본과 발표

표 아래의 탭에서 **원본**과 **사본**을 전환합니다. **+ 사본 추가**를 누르면 현재 원본의 업무와 보기, 또는 현재 사본을 복사합니다. 사본 이름의 기본값은 오늘 날짜에 ‘의 사본’을 붙인 `YYYY-MM-DD의 사본`이며 같은 이름이 있으면 `YYYY-MM-DD의 사본 (2)`, `YYYY-MM-DD의 사본 (3)` 순으로 번호를 붙입니다. 생성 창에서 **확인**을 누르면 사본을 만듭니다. 사본 이름은 최대 50자이며 팀 안에서 중복될 수 없습니다. 원본 바로 오른쪽에 추가 버튼이 있고, 사본은 최근에 만든 것부터 왼쪽에 표시합니다. 탭을 더블클릭하거나 메뉴의 **이름 변경**을 선택하면 탭 안에서 이름을 입력합니다. **Enter** 또는 입력칸 밖으로 포커스를 옮기면 저장하고 **Esc**로 취소합니다. 탭 메뉴에서 사본을 삭제할 수 있습니다. 맨 오른쪽 화살표는 탭 영역을 좌우로 스크롤하며 해당 방향의 끝에서는 비활성화됩니다.

사본은 별도의 보기/수정 전환 없이 바로 편집하며 셀·서식·행 추가·복제·삭제·순서·보기 설정을 자동 저장합니다. 저장 후에도 현재 편집 세션의 **실행취소 / 재실행**을 사용할 수 있습니다. 문서는 표와 별도로 자동 저장합니다. 표를 실행취소해도 독립적으로 저장한 문서 내용은 되돌리지 않습니다.

팀원·팀장·시스템 관리자는 접근 가능한 팀의 사본을 편집하고, 열람자는 읽기만 가능합니다. 사본 수정과 삭제는 원본 업무에 영향을 주지 않습니다. 원본으로 돌아오면 이전 필터·보기·스크롤을 복원합니다.

사본에서도 **저장된 필터**를 적용하면 표 위에 필터 이름과 적용된 조건을 표시합니다. 이 표시줄에서 조건을 바꾸거나 **필터 보기 종료**로 해제할 수 있으며, 사본의 조건 변경은 원본의 필터 설정에 영향을 주지 않습니다.

자동 저장에 실패하면 입력을 유지하고 **저장 재시도**를 제공합니다. 다른 사용자의 수정과 충돌하면 입력을 확인한 뒤 **최신 내용 불러오기**로 저장하지 못한 표 변경을 폐기할 수 있습니다. 저장에 실패한 상태에서는 다른 사본으로 이동하지 않습니다.

**발표 모드**는 원본과 사본에서 사용할 수 있습니다. 발표 중에는 편집을 막고 표를 넓게 표시하며 종료하면 이전 화면으로 돌아옵니다.

## 7. 가져오기·내보내기

1. 원본 시트를 XLSX로 반출해 별도 보관합니다.
2. 팀·팀원과 필요한 속성·선택값을 먼저 등록합니다.
3. 가져오기에서 대상 시트·연도·담당자 연결·예외 목록을 검토합니다. 미리보기는 업무를 변경하지 않습니다.
4. 최신 시트는 업무로, 과거 날짜별 시트는 사본으로 적용할 수 있습니다. 동일 파일·팀·시트·모드·연도 재시도는 중복 생성하지 않습니다.
5. 행 수·날짜·담당자·서식·숨김 구간을 원본과 대조합니다. 가져온 숨김·크기는 현재 보기에 반영됩니다. 저장된 필터에는 포함하지 않습니다.

파일은 최대 25MB, 150시트, 시트당 20,000행·500열을 처리합니다. 압축 해제 크기도 검사합니다. 첫 20행에서 헤더를 찾고 날짜는 월요일 주차 키로 연결합니다. 담당자 이름이 중복되면 직접 연결해야 합니다. 같은 팀에 정의된 동적 속성은 표시명으로 연결합니다.

수식은 파일에 저장된 결과값으로 변환합니다. 결과값 없는 수식, 병합, 조건부 서식, 차트·매크로, 부분 서식 등은 검토가 필요합니다. 이관은 변경분 자동 병합 기능이 아니므로 원본을 보관하고 결과를 확인하세요.

| 내보내기 | 포함 범위 |
| --- | --- |
| XLSX | 값과 기본 셀 서식 |
| CSV | 값. 수식으로 실행될 수 있는 텍스트는 작은따옴표로 보호 |
| JSON | 업무 ID·날짜 키·서식·개인 보기·관리자 사본 등 |

현재 표시 범위와 기준 연도 전체를 구분하여 내보냅니다. 현재 보기는 두 해의 업무와 날짜 열도 함께 반출합니다. 기준 연도 전체는 제목에 표시된 한 해를 대상으로 합니다. 파일명은 `graeboard-연도.확장자`이며 두 해의 현재 보기는 `graeboard-2026-2027.확장자`처럼 표시합니다. JSON 직접 재가져오기는 제공하지 않습니다. 계정·권한·이력을 포함한 전체 복구는 [SQLite 백업·복구](OPERATIONS.md#백업과-복구)를 사용하세요.
